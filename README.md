# AlgoViz

### Interactive Algorithm & Data Structure Visualizer

AlgoViz is a React-based interactive platform designed to make algorithms and data structures easier to understand through visualizations, step-by-step execution, and interactive controls.

Instead of only reading about an algorithm, AlgoViz lets you **see how it works**.

---

## ✨ Features

- Interactive algorithm visualizations
- Step-by-step execution
- Play, pause, and reset controls
- Adjustable visualization speed
- Random data generation
- Algorithm-specific educational explanations
- Time and space complexity information
- Interactive data structure operations
- Dark-themed responsive interface
- Collapsible navigation sidebar

## 🎯 How It Works

AlgoViz follows a simple learning flow:

**Select → Visualize → Execute → Understand**

1. Select an algorithm or data structure.
2. Generate or provide the required data.
3. Start the visualization.
4. Observe the algorithm's execution step by step.
5. Use the educational section to understand the underlying logic and complexity.
